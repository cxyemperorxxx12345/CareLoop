愈见 CareLoop 是构建于百度秒哒平台的出院患者照护应用，覆盖出院后 2–8 周过渡期。创作理念是把照护做成患者、家属、护士三方共享的可追溯状态机：漏服自动沿「本人→家属→护士站」升级链流转，症状经红旗规则与大模型双通道三级分诊直通医护预警，家属代打卡全程带来源标注。AI 贯穿始终：出院小结拍照解析、引用式 RAG 问答、随访报告自动生成，并以个人基线机制实现「每个患者唯一的对照是他自己」。

愈见 CareLoop，构建于百度秒哒平台的出院患者三方协同照护应用。核心是「漏服升级链 + 三级分诊 + 家属协同来源标注」三大机制组成的状态机：患者端打卡与症状自查、家属端代打卡、医护端预警中心与照护时间轴，跨端实时同步。AI 能力含出院小结拍照解析、规则与大模型双通道分诊、引用式 RAG 问答、报告自动生成与个人基线对照。

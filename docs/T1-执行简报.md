## 二、第 2 条 · 知识库换行转义

根因：写入链路把换行 JSON 字符串化，落库成「字面反斜杠 + n」两个字符。

- `src/lib/api.ts` 新增导出 `normalizeKnowledgeText(input: string): string`
  - 字面 `\r\n` → 真换行 → 字面 `\n` → 真换行（顺序不能反）→ 真实 CRLF/CR → LF → 连续 3+ 换行压缩为 2 → `trim()`
- 写入端：`clinicianApi.saveKnowledge()` 的 insert / update 两条分支对 `title` 与 `content` 归一化。
- 读取端：`clinicianApi.knowledge()` 返回前对每行归一化 —— 存量脏数据即使没跑迁移也能立刻正确显示。
- 存量清洗：`supabase/migrations/00013_t1_knowledge_newline_normalize.sql`（幂等，可重复执行）。
  用 `position()` 而非 `LIKE` 判定，因为 LIKE 的默认转义符就是反斜杠，`'%\n%'` 会被解析成"匹配字母 n"。

**验证步骤**：医护端新增一条带换行的资料 → 保存 → 直接看卡片是否换行生效；再执行 00013 迁移 → 老资料换行恢复。

## 三、第 3 条 · 消息重复（插入侧幂等）

根因确认：`reminder-scan` 被 pg_cron 每分钟调用，边界条件下对同一条提醒重复 INSERT。

- `supabase/migrations/00012_t1_messages_dedup_index.sql`：把 00011 的**部分**唯一索引换成**非部分**唯一索引 `messages(patient_id, dedup_key)`。PostgREST 的 `ON CONFLICT` 无法推断部分索引；而 Postgres 唯一索引把 NULL 视为互不相等，历史行无需回填即可安全替换。
- `supabase/functions/reminder-scan/index.ts`：新增 `insertMessageOnce()`（先查后插 + 23505 唯一冲突兜底），6 处 `messages.insert` 全部改为幂等写入，并带上 dedup_key：
  - `med:l0:{reminder_id}` / `med:l1:...` / `med:l2:...` / `med:l3:...`（L3 的两条互斥路径共用一个 key）
  - `med:rearm:{reminder_id}:{YYYY-MM-DDTHH}`（snooze 重推按**小时窗口**去重，避免把当天合法的二次稍后提醒也误杀）
- `supabase/functions/triage-symptom/index.ts`：消息带 `dedup_key = 'triage:{symptom_check_id}'`，一次分诊只产生一条消息。

## 四、第 5 条 · checkins 日粒度

- 确认事实：只有 `created_at timestamptz`，无独立 date 字段；当前**没有** `(patient_id, created_at::date)` 唯一限制，同一天可插多条。
- 约定已固化进 `supabase/migrations/00014_t1_checkins_daily_upsert.sql` 文件头：
  1. 日粒度 = `created_at::date`，作为"当日唯一体征快照"标准；
  2. 禁止裸 INSERT，先查后插/覆盖；
  3. 播种必须显式指定 `created_at`（如每日 08:00），保证 9 天序列均匀连续。
- 新增 RPC `public.upsert_daily_checkin(...)`（`SECURITY DEFINER`，返回 uuid），逻辑：
  `coalesce(p_created_at, now())` → `::date` → 查当日最新一条 → 有则 UPDATE 覆盖（传 NULL 即清空，语义已写明）→ 无则 INSERT。
  - 带归属守卫：`auth.uid()` 非空时必须是本人或医护，否则抛异常；service_role 放行供播种使用。
  - 未加唯一索引（表达式索引会让 PostgREST upsert 推断失败），统一走先查后插。
- `src/pages/patient/CheckinPage.tsx`：患者端打卡改为调用该 RPC，不再裸 insert。
- **时区提醒**：`::date` 依赖会话 TimeZone（Supabase 默认 UTC）。若 T2 需要"北京时间口径"的日界，把 `v_date` 一行改成 `(v_ts AT TIME ZONE 'Asia/Shanghai')::date`，并同步前端聚合口径。

# 愈见 CareLoop · 交接手册

> 面向新协作者：读完这一份 + README，即可接手开发。最后更新：2026-10-12。

## 1. 这个项目是什么

无代码创新比赛（医疗健康赛道）作品：出院患者全周期照护。三端角色——患者（手机）、家属（手机）、医护（Web 工作台）。核心不是单个功能，而是三个机制串成的**出院过渡期处置闭环**：

1. **漏服升级链 L0→L3**：站内提醒 → 30min → 短信（演示通道）→ 通知家属（可处置任务）→ 护士站预警，任意打卡即终止
2. **症状三级分诊直通医护**：红旗规则兜底 + MiniMax 综合分级，黄/红自动生成医护端预警
3. **家属协同带来源标注**：家属代打卡记录 `operator_type='family'`，「仍无响应」转医护回电（不升级红色）

跨端数据流是真实的（Postgres + RLS + Edge Functions），不是前端 mock。

## 2. 架构决策（为什么这么搭）

| 决策 | 理由 |
|---|---|
| Vite + React + TS（非 Next.js） | Miaoda 源码导出模板；比赛演示无 SEO 需求 |
| 托管 Supabase，本地不起库 | 前后端直连；RLS 管权限；Edge Functions 跑 AI 调用 |
| 迁移只增不减（00001→00018） | 线上库无版本管理工具，靠 SQL Editor 按序号应用；`supabase/ops/full_schema_*.sql` 是全新库一次性合集 |
| 提醒状态机每药一行，消息/预警按组合并 | 状态机需要 per-(plan,slot) 粒度；但患者感知的提醒按时段合并，避免告警疲劳 |
| 红色预警只给分诊红旗与危险体征 | 红标语义不被稀释；漏服升级最高到黄色「需医护回电」 |
| 三档字号（小/中/大）挂 html class | Tailwind 字号多为 rem 单位，根字号缩放全覆盖；任意 px 值在 index.css 按档位显式覆盖 |

## 3. 关键机制速查

- **漏服升级链**：`supabase/functions/reminder-scan/index.ts`（pg_cron 每分钟）。分组键 = 患者+时段+状态+升级级数；dedup_key 含分组成员 id。打卡/稍后提醒在前端按 slot 整组生效（`MedicationsPage` / `FamilyMedicationsPage` 的 reminders update 不带 plan_id）。
- **分诊规则**：`supabase/functions/triage-symptom/index.ts`。红旗词 8 组带口语变体；命中且严重度≥5（或多词叠加）才判红；体温≥39/收缩压≥180 直接红；低严重度命中判黄。规则全文在患者端「分级规则说明」面板公开。
- **预警聚合**：`src/pages/clinician/AlertsPage.tsx` 默认按患者分组（产生层已在 reminder-scan 合并，展示层再按患者聚合）。
- **消息幂等**：`messages.dedup_key` 唯一索引 + 写入端先查后插。
- **适老化字号**：`src/lib/font-scale.ts` + `index.css` 的 `html.fs-*`；localStorage 键 `careloop:font-scale`。
- **桌面演示布局**：`src/components/layouts/MobileShell.tsx`——移动端通栏，md+ 渲染设备框（患者/家属端）；医护端保持桌面工作台形态。

1. **`tasks/handoff.md` 已过期**：描述的是 Next.js + Prisma + docker-compose，与实际代码完全不符。以本手册和 README 为准。

3. **演示密码漂移（已修）**：登录页一键填入的密码曾与迁移种子不一致（线上被手工改过），迁移 00018 已对齐。重建库后直接可用。
4. **`dist/` 是旧产物**：gitignore 但本地留着，路由级代码分割后的构建需重新 `pnpm build` 才会更新；别拿旧 dist 判断包体积。
5. **网络环境**：GitHub 推送走 SSH（`git@github.com`，本机已配 SSH over 443）；pnpm registry 必须 npmmirror。
6. **长跑命令**：dev server 等常驻进程用后台方式启动，前台跑会被超时连带杀掉。
7. **Windows 文件名**：仓库里有个 `nul` 垃圾文件（Git Bash 历史遗留），已 gitignore，删不掉也别管。
8. **`.env` 含 anon key 且已提交**：anon key 设计上可公开（RLS 保护），但上线前建议评估是否改走环境变量注入。
